# Project Design & Status

- [x] Basic Streamlit dashboard structure.
- [x] Sidebar navigation between "Deep Dive" and "Screener".
- [x] Data fetching from NSE source for indices and historical values.
- [x] Merge logic for Price and Valuation ratios.
- [x] Main time-series chart with multiple overlays.
- [x] Metric summary cards (Current vs Median).
